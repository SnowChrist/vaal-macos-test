# VAAL для macOS

Нативная учебная версия ВААЛ-мини для анализа русских и украинских слов и текстов.

## [Скачать VAAL для Mac](https://github.com/SnowChrist/vaal-macos-test/releases/download/v1.5-test/VAAL-macOS-arm64.zip)

Подходит для Mac с чипом Apple Silicon (M1 или новее) и macOS 13 или новее.

1. Скачайте ZIP в браузере и распакуйте его.
2. Перетащите `VAAL.app` в папку «Программы» и откройте.
3. Если macOS остановит первый запуск, откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть» рядом с сообщением о VAAL.
